DesignTokens

Ті самі формули ThemeScale, що в коді. Нові: success, warning, info та текстові відтінки *Text для варіантів, які пишуть кольором по фону. Біля пари вказано контраст за WCAG; позначка «нижче 4.5» означає, що текст читається погано.

Типографіка: Adwaita Sans для тексту, JetBrains Mono для коду й клавіш. Радіуси 4 · 8 · 12 · 16, відступи 4 · 8 · 12 · 16 · 24, переходи кольорів themeMs = 220.

Правила API

UTheme(tokens, UThemeConfig(button = UButtonDefaults(variant = UVariant.Soft))) {
  UButton("Зберегти", onClick = ::save)          // бере стандарти з теми
  UButton(
    "Видалити",
    onClick = ::delete,
    color = UColor.Error,                         // enum, а не колір
    variant = UVariant.Outline,
    size = USize.Sm,
    ui = UButtonUi(base = Modifier.radius(999)),  // перевизначення слотів
  )
}
UColorPrimary, Secondary, Success, Info, Warning, Error, Neutral
UVariantSolid, Outline, Soft, Subtle, Ghost, Link
USizeXs, Sm, Md, Lg, Xl
станконтрольований: value + onValueChange, open + onOpenChange
порядоктема → варіант → config.ui → ui екземпляра; пізніше перемагає
назваaccessibleLabel обов'язковий там, де немає видимого тексту
